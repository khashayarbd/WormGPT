## معرفی

**WORMGPT** یک رابط گفت‌وگو (Chat UI) است که کل تجربهٔ کاربری را در یک فایل `index.html` جمع می‌کند: نمایش جریان‌محور پاسخ‌ها، رندر Markdown، هایلایت کد، پیش‌نمایش زندهٔ HTML، پیوست فایل و تصویر، ورودی صوتی، تاریخچهٔ گفتگو با ذخیره‌سازی محلی، پوستهٔ روشن/تیره و رابط دوزبانه.

هدف طراحی، **سادگی استقرار** است: فایل را روی هر هاست استاتیک بگذارید، آدرس بک‌اند را در یک فایل تنظیمات بنویسید و تمام.

> این پروژه یک «کلاینت» است؛ تولید پاسخ توسط سرویس مدل انجام می‌شود. کلاینت به‌طور پیش‌فرض درخواست‌ها را به مسیر `/api/chat` می‌فرستد و در صورت خطا، مسیرهای جایگزین را امتحان می‌کند.

## ویژگی‌ها

### گفت‌وگو و پاسخ
- **پاسخ جریان‌محور (streaming)** با پشتیبانی از پروتکل NDJSON
- **پنل تفکر مدل** (Reasoning) به‌صورت بازشو، جدا از متن نهایی
- **حالت تفکر** قابل روشن/خاموش کردن (با دستورالعمل مستقیم به مدل)
- **تولید دوباره** و **توقف تولید** پاسخ، **کپی** پیام
- روی هر بلوک کد: **کپی**، **دانلود** و **اجرا** (برای HTML/CSS/JS)
- نمایش هوشمند خطاها با پیام فارسی و قابل‌فهم

### نمایش محتوا
- رندر Markdown: سرتیتر، لیست، جدول، نقل‌قول، لینک، تصویر، خط جداکننده
- **هایلایت کد** برای ده‌ها زبان برنامه‌نویسی + دکمهٔ کپی
- **پیش‌نمایش زندهٔ HTML** در پنجرهٔ مستقل (اجرای کد HTML پاسخ)
- **نمایشگر فایل** برای دیدن کد فایل‌های پیوست‌شده
- **لایت‌باکس تصویر** با گزینهٔ دانلود و اشتراک‌گذاری

### ورودی‌ها
- پیوست **فایل متنی/کد** و **تصویر** (تا ۵ فایل هم‌زمان)
- **ورودی صوتی** با تبدیل گفتار به متن (Web Speech API)
- ارسال با دکمهٔ ارسال (یا دکمهٔ ماوس/لمس روی آیکون)
- بزرگ‌نمایی خودکار textarea و شمارش وضعیت (تولید/آماده)

### تجربهٔ کاربری
- **تاریخچهٔ گفتگو** با گروه‌بندی «امروز»، تغییر نام، حذف تکی و حذف همه
- **پوستهٔ روشن/تیره** با ذخیره‌سازی انتخاب کاربر
- **رابط دوزبانه**: فارسی (پیش‌فرض، RTL) و English (LTR) — تغییر خودکار جهت صفحه
- طراحی **واکنش‌گرا** با سایدبار کشویی در موبایل
- اعلان‌های کوتاه (Toast) برای همهٔ رویدادها
- دسترس‌پذیری: `aria-label`، `role`، بستن مودال‌ها با `Esc`، فوکوس واضح روی کنترل‌ها

## ساختار پروژه

```
project/
├── index.html     ← کل رابط کاربری (HTML + CSS + JS)
├── config.js      ← تنظیمات اتصال (آدرس بک‌اند)
└── prompt.js      ← دستورالعمل سیستمی مدل (System Prompt)
```

```html
<!-- index.html، ابتدای <head> -->
<script src="config.js"></script>
<script src="prompt.js"></script>
```

| فایل | الزامی؟ | نقش |
|---|---|---|
| `index.html` | ✅ | کل برنامه |
| `config.js` | ⚠️ توصیه‌شده | تعریف `window.WORMGPT_API` (آدرس بک‌اند) |
| `prompt.js` | ⚠️ توصیه‌شده | تعریف `window.WORMGPT_SYSTEM_PROMPT` (شخصیت و قواعد مدل) |

اگر یکی از این دو فایل نباشد، برنامه خطا نمی‌دهد؛ در کنسول هشدار می‌دهد و با مقادیر پیش‌فرض کار می‌کند.

## پیش‌نیازها

- یک مرورگر مدرن (بدون نیاز به Node.js، بیلد یا پکیج)
- یک **بک‌اند سازگار** که مسیر `POST /api/chat` را ارائه دهد (اختیاری ولی توصیه‌شده)
- برای ورودی صوتی: میکروفون + مرورگری که `SpeechRecognition` را پشتیبانی کند (Chrome/Edge)
- برای پیوست تصویر و اجرای پیش‌نمایش: دسترسی شبکه به دامنه‌های مقصد

## پیکربندی

### `config.js`
```js
// آدرس بک‌اند شما (بدون اسلش انتهایی)
window.WORMGPT_API = 'https://api.example.com';

// اگر خالی بماند، درخواست‌ها به همان دامنهٔ فعلی + /api/chat می‌روند
```

### `prompt.js`
```js
window.WORMGPT_SYSTEM_PROMPT = `
تو یک دستیار هوش مصنوعی فارسی‌زبان و دقیق هستی.
- پاسخ‌ها را کوتاه، ساختارمند و کاربردی بنویس.
- برای کد، همیشه توضیح فارسی همراه کد بده.
- اگر اطلاعات کافی نیست، صریح بپرس.
`;
```

### ثابت‌های داخل `index.html`
| ثابت | مقدار پیش‌فرض | کاربرد |
|---|---|---|
| `MODEL_ID` | `DeepSeek-R1-0528` | شناسهٔ مدلی که به بک‌اند ارسال می‌شود |
| `MODEL_LABEL` | `WORMGPT` | نام نمایشی مدل در نوار بالا |
| `MAX_ATTACH_FILES` | `5` | حداکثر تعداد فایل پیوست |
| `ATTACH_MAX_BYTES` | `200 KB` | سقف حجم هر فایل متنی |
| `ATTACH_IMG_MAX_BYTES` | `4 MB` | سقف حجم هر تصویر |

## نحوهٔ اتصال به مدل

کلاینت با مسیر اصلی زیر صحبت می‌کند:

```
POST {WORMGPT_API}/api/chat
Content-Type: application/json
```

**بدنهٔ درخواست**
```json
{
  "model": "DeepSeek-R1-0528",
  "system": "دستورالعمل سیستمی …",
  "search": true,
  "messages": [{ "role": "user", "content": "سلام" }],
  "images": [{ "dataUrl": "data:image/png;base64,…" }]
}
```

**پاسخ ساده (JSON)**
```json
{ "ok": true, "text": "پاسخ مدل …", "reasoning": "تفکر مدل …" }
```

**پاسخ جریان‌محور (NDJSON)** — هر خط یک آبجکت JSON:
```json
{"stage":"delta","delta":"پاسخ ","reasoning_delta":""}
{"stage":"generating"}
{"ok":true,"text":"پاسخ کامل","reasoning":"…"}
```

اگر مسیر `/api/chat` در دسترس نباشد یا پاسخ نامعتبر برگرداند، کلاینت به‌صورت خودکار مسیرهای جایگزین (سرویس‌های عمومی سازگار) را امتحان می‌کند و اولین پاسخ معتبر را نمایش می‌دهد. برای استقرار جدی، همیشه بک‌اند اختصاصی خودتان را تنظیم کنید.

> **جست‌وجوی وب:** کلاینت پیش از ارسال، برای پرسش‌های غیرسلام، خلاصه‌ای از نتایج ویکی‌پدیا (فارسی و انگلیسی) را به‌عنوان «زمینه» به مدل می‌دهد. این کار سمت کلاینت انجام می‌شود و به مدل گفته می‌شود هرگز به جست‌وجو اشاره نکند.

## زبان و ظاهر

| قابلیت | جزئیات |
|---|---|
| زبان پیش‌فرض | فارسی (`fa`، جهت `rtl`) |
| زبان دوم | English (`en`، جهت `ltr`) |
| تغییر زبان | تنظیمات → «زبان» → فارسی / English (در `localStorage` ذخیره می‌شود) |
| پوسته | `dark` (پیش‌فرض) و `light` — از طریق متغیرهای CSS |
| فونت‌ها | `Inter` + `Noto Sans Arabic` (متن) و `JetBrains Mono` (کد) |

همهٔ رشته‌های متنی در یک دیکشنری مرکزی به نام `I18N` داخل فایل قرار دارند؛ برای افزودن زبان جدید کافی است کلید تازه‌ای (مثلاً `de`) با همان کلیدواژه‌ها اضافه کنید و در `data-lang` دکمه‌ای در بخش تنظیمات ثبتش نمایید.

## داده‌های محلی (localStorage)

هیچ داده‌ای به‌جز درخواست‌های مدل از مرورگر خارج نمی‌شود؛ تاریخچه کاملاً محلی است.

| کلید | محتوا |
|---|---|
| `wormgpt_chats` | آرایهٔ گفتگوها و پیام‌ها (JSON) |
| `wormgpt_chats_cleared` | زمان آخرین «حذف همه» (برای همگام‌سازی بین تب‌ها) |
| `wormgpt_theme` | `dark` یا `light` |
| `wormgpt_lang` | `fa` یا `en` |
| `wormgpt_search` | `on` / `off` — وضعیت جست‌وجوی وب |
| `wormgpt_think` | `on` / `off` — وضعیت حالت تفکر |

> اگر فضای `localStorage` پر شود، قدیمی‌ترین گفتگوها به‌طور خودکار کوتاه می‌شوند تا گفتگوهای جدید ذخیره شوند (پیام «فضا پر شده است…» نمایش داده می‌شود).

## شخصی‌سازی

### تغییر رنگ‌ها
همهٔ رنگ‌ها متغیر CSS هستند؛ در ابتدای فایل، بخش `:root`:
```css
:root {
  --accent: #ff2233;        /* رنگ اصلی برند */
  --bg: #0a0506;            /* پس‌زمینه */
  --surface: #17090c;       /* سطح کارت‌ها */
  --radius: 10px;           /* گردی گوشه‌ها */
}
[data-theme="light"] {
  --accent: #d4001a;
  --bg: #fffafa;
}
```

### تغییر نام و لوگو
- نام نمایشی: `MODEL_LABEL` و متن‌های `WORMGPT` در `index.html`
- فاوآیکون: تگ `<link rel="icon">` (SVG درون‌خطی `data:`)
- رنگ نوار مرورگر: `<meta name="theme-color">`

### جایگزینی فونت
در `:root` مقدار `--font` و `--mono` را تغییر دهید و لینک فونت گوگل در `<head>` را به‌روز کنید.

## عیب‌یابی

| نشانه | علت احتمالی | راه‌حل |
|---|---|---|
| «فایل prompt.js بارگذاری نشد» در کنسول | `prompt.js` وجود ندارد یا خطای سینتکس دارد | فایل را بسازید و `window.WORMGPT_SYSTEM_PROMPT` را تعریف کنید |
| «اتصال به سرور ممکن نشد» | آدرس بک‌اند غلط یا CORS | `window.WORMGPT_API` را بررسی کنید و هدرهای CORS سمت سرور را باز کنید |
| «اتصال به سرویس‌دهنده یا مسیر /api/chat ممکن نشد» | مسیر اشتباه یا بک‌اند خاموش | وجود مسیر `POST /api/chat` را تست کنید |
| «سرویس‌دهنده در این لحظه مشغول است» | محدودیت نرخ/سهمیهٔ سرویس | چند لحظه بعد دوباره تلاش کنید یا کلید/سهمیه را بررسی کنید |
| میکروفون کار نمی‌کند | مجوز مرورگر یا نبود `SpeechRecognition` | مجوز میکروفون را بدهید؛ از Chrome/Edge و `https` یا `localhost` استفاده کنید |
| پیش‌نمایش HTML باز نمی‌شود | مسدودسازی iframe سمت کاربر | پاپ‌آپ/iframe را برای دامنه مجاز کنید |
| پیام «فضا پر شده است» | پر شدن `localStorage` | گفتگوهای قدیمی را حذف کنید (تنظیمات → پاک کردن همهٔ گفتگوها) |
| فونت‌ها در پیش‌نمایش آفلاین لود نمی‌شوند | نیاز به دسترسی به `fonts.googleapis.com` | فونت را محلی میزبانی کنید یا از فونت سیستمی استفاده کنید |

## حریم خصوصی و امنیت

- **تاریخچه فقط در مرورگر شما ذخیره می‌شود** (`localStorage`) و روی هیچ سروری نگه‌داری نمی‌شود.
- درخواست‌ها با `credentials: 'omit'` ارسال می‌شوند؛ کوکی سشن همراه نمی‌شود.
- هرگز **کلید API** را در `config.js` یا `index.html` قرار ندهید — کلید باید فقط در بک‌اند بماند.
- محتوای مدل پیش از نمایش، پاک‌سازی/فرار داده می‌شود (escape) و فقط پیش‌نمایش HTML به‌صورت آگاهانه اجرا می‌شود؛ با این حال اجرای کد ناشناس در پیش‌نمایش می‌تواند ریسک داشته باشد — فقط کد قابل‌اعتماد را اجرا کنید.
- برای استفادهٔ عمومی، دسترسی به بک‌اند را با محدودیت نرخ (rate limit) و احراز هویت محافظت کنید.

## تغییرات نسخهٔ فارسی

این نسخه از نسخهٔ عربی پروژه فارسی‌سازی کامل شده است:

- ترجمهٔ همهٔ متن‌های رابط کاربری، دیکشنری `I18N` (۱۰۵ کلید)، عنوان صفحه و متا تگ‌ها
- فارسی‌سازی پیام‌های runtime: خطاها، وضعیت میکروفون، اعلان‌ها، لایت‌باکس
- فارسی‌سازی دستورالعمل زبانی ارسالی به مدل و الگوی تشخیص سلام/خطا
- تغییر کد زبان از `ar` به `fa` (`<html lang="fa">`، کلید `I18N`، `localStorage`، دکمهٔ «فارسی»)
- منبع جست‌وجو از ویکی‌پدیای عربی به **ویکی‌پدیای فارسی** تغییر کرد
- ساختار، استایل، منطق و بخش انگلیسی **بدون تغییر** باقی مانده‌اند
